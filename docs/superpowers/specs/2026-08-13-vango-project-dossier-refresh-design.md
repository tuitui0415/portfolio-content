## 已确认信息

- 项目名称：Vango
- 项目性质：团队项目
- 项目形式：用于浏览与介绍游戏作品的 Figma 交互原型
- 时间：2019.09—2019.12
- 工具：Figma
- 职责：沿用现有档案中的“UI 设计”；不补充团队规模或未经确认的个人贡献

## 文案

中文项目介绍：

> Vango 是一款用于浏览与介绍游戏作品的 Figma 交互原型。原型包含作品发现、分类筛选、详情浏览、搜索、评论、个人主页及内容发布等界面流程。

英文项目介绍：

> Vango is a Figma interactive prototype for discovering, browsing, and presenting game projects. It includes flows for discovery, filtering, project details, search, comments, user profiles, and content publishing.
