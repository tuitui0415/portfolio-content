# 克制化公开展示设计

## 目标

首页以最少的信息说明“是谁、做过什么、从哪里进入”，不使用人物背景、宣传口号或主观评价。项目页只公开已经完成的工作、设计方法与实现结果，不展示缺点、限制或未完成事项。

## 首页

- 纯色深色背景与细线框架，不使用人物、场景插画、漂浮粒子或装饰性档案卡。
- 只展示姓名、客观身份信息，以及“浏览项目”“个人信息”两个入口。
- 中文与英文使用相同的信息层级，移动端不改变阅读顺序。

## 项目页

- 保留项目摘要、时间、职责、团队、工具、设计目标、核心机制和关键决策。
- 不公开“迭代与验证”段落，因为该字段同时包含内部复盘、限制和未完成事项。
- 原始项目 JSON 不删除，继续作为简历与网站同步更新时的内容仓库。

## 验收

- 中英文首页没有人物图、宣传式开场和作品数量装饰。
- About 开场改为可核验的学历与项目经历描述。
- 项目详情没有“限制、尚未完成、not run、time constraints”等公开表述。
- 桌面、移动端和键盘操作仍可正常访问所有主要入口。
