# A Room Without Wall

## 中文概述

Game Jam 团队项目。魏允瀚负责团队组织、游戏策划与程序开发，并编写 Unity Shader 将平面场景投射至球面，形成独特的空间体验。

## English Overview

A Game Jam team project in which Yunhan Wei organized the team, contributed game design and programming, and authored a Unity shader that projected a planar scene onto a sphere.
