# Le Boulanger! Bakery of Hell!

## 中文概述

以 `Hell's Bakery` 名称发布的网页 Game Jam 项目。魏允瀚使用 Phaser 3 与 JavaScript 参与核心玩法开发、关卡设计和游戏节奏调优。

## English Overview

A web Game Jam project published as `Hell's Bakery`. Yunhan Wei contributed to core gameplay, level design, and pacing using Phaser 3 and JavaScript.
