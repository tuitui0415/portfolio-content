# 隔离 / Isolation

## 中文概述

《Isolation》是一款以疫情封控下的孤独、自我认知与社会形象为主题的叙事卡牌游戏。玩家通过与邻居对话塑造他人眼中的角色形象，这一形象会动态影响牌局中的弃牌概率；镜子则将外部评价反馈为角色的自我认知。

## English Overview

Isolation is a narrative card game about loneliness, self-perception, and social identity during lockdown. Dialogue choices shape how neighbors perceive the protagonist, that perception changes discard probability in the card game, and a mirror reflects the identity back to the player.

## 项目信息 / Project Facts

- 类型：个人项目
- 时间：2021.12-2022.06
- 职责：游戏设计、程序开发、2D 角色、3D 环境与道具、UI 动画
- 工具：Unity、Photoshop、Maya、ZBrush、Spine
- 试玩：室友参与牌局测试

## 设计目标 / Design Goals

- 探索孤独状态下个人如何看待自己与他人。
- 把“角色形象”从叙事概念转化为影响牌局的系统变量。
- 通过 3D 环境与 2D 角色的视觉冲突强化疏离感。

## 核心玩法 / Core Play

玩家在封控社区中与邻居交谈，通过选择建立傲慢、自卑或其他社会形象。牌局借鉴德州扑克的概率判断和对手阅读，并使用麻将式图形替代数字；角色形象会改变弃牌成功的动态概率。

## 关键决策 / Key Decisions

- 镜子是唯一直接反馈角色自我认知的系统。
- 鸟笼与竹子构成卡背意象，将束缚主题与麻将文化连接起来。
- 室内外场景的构图、道具与整体脏旧质感间接刻画角色生活状态。
