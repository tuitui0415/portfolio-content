# Vango

## 中文概述

Vango 是一款用于浏览与介绍游戏作品的团队 Figma 交互原型。原型包含作品发现、分类筛选、详情浏览、搜索、评论、个人主页及内容发布等界面流程。

## English Overview

Vango is a team Figma interactive prototype for discovering, browsing, and presenting game projects. It includes flows for discovery, filtering, project details, search, comments, user profiles, and content publishing.
