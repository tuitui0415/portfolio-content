# Smile Train VR

## 中文概述

UCSC ASSIST Lab 与 Smile Train 合作开发的双人 VR 教育与心理支持游戏，通过生活情境帮助唇腭裂青少年建立自信和社会情感能力。魏允瀚参与程序开发，实现对话、文字、导航和 Photon 多人交互。

## English Overview

A two-player VR educational and psychosocial support game developed by UCSC ASSIST Lab with Smile Train. Yunhan Wei contributed programming for dialogue, text, navigation, and Photon multiplayer interaction.
